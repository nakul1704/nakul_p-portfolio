PORTFOLIO MEDIA

Open "nakul portfolio.html" to view the portfolio.
Each card shows one media item at a time. Use the arrows, swipe horizontally
on touch screens, or focus the gallery and use the keyboard arrow keys.
Arrows and the counter are hidden when a card has only one item. Navigation wraps around.
Videos pause when you leave their slide; playback never starts automatically.

Game folders under assets/media/:
  lost-trance/
  bin-it-to-win-it/
  rhythm-riot/
  heist-protocol/
  Love-Story/
The original four game folders contain images/ for future pictures.
Love Story images are stored directly in Love-Story/.

ADDING AN IMAGE
1. Put the image in the relevant game's images/ folder.
2. In the HTML, locate that game's media-track and add a slide inside it:

   <div class="media-slide" role="group" aria-roledescription="slide">
       <img class="project-media"
            src="assets/media/bin-it-to-win-it/images/example.jpg"
            alt="Describe the screenshot" loading="lazy">
   </div>

3. Update the path and description. Save and refresh the page.
The arrows and counter automatically include all slides in the track.
Adding a file to the folder alone does not add a slide to the page.

For an additional video, use the same slide wrapper with a <video> element,
following the existing examples. Use MP4 (H.264/AAC) for browser compatibility.

Lost Trance.mp4 and Lost Trance.mkv contain the compressed 1600 x 1000,
30 fps version of the full video. The website uses the MP4.
All videos in this archive are below 100,000,000 bytes each.
